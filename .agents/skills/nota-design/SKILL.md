# Nota design language — Studio

Saine's design system (`../saine/DESIGN.md`) applied to Nota: neutral greys stepped in a
few exact tones (well · ground · panel · raised), flat panels butted against dark 1px
seams, small crisp type, and **one orange accent that appears only where something is
live or chosen**. Two variants of one system — **Dark** (the default) and **Light** (the
same roles in light greys). Preferences → Appearance picks Dark / Light / System; the
switch is live. `DESIGN.md` is Saine's system as Nota implements it, plus the departures
the project accepted.

If `DESIGN.md` / `DESIGN.html` disagree with the theme files, **the theme files win** and
the docs need fixing. Say so rather than propagating the drift.

> This skill deliberately does **not** restate token values. An earlier version did, and

## Non-negotiables

Most of these are enforced by `DesignTokenCheck`; the smoke test fails when one breaks.

- **No literals in views.** XAML: `{DynamicResource Brush.*}` / `{DynamicResource Shadow.*}`
  (a `StaticResource` cannot follow the variant) and
  `{StaticResource Radius.*|Control.*|Space.*}`. C#: `NotaPalette` (a slot,
  `Wash(slot, alpha)`, `InkOn(fill)`, `Ink("#hex")` for a one-off device hue),
  `NotaRadius`, `NotaSize`, `NotaSpace`, `NotaFonts`, `NotaType`. No hex outside `Ink()`,
  no RGB typed as numbers, no `Colors.X` / `Brushes.X` except `Transparent`, no font
  family names, no `new BoxShadows` in a view.
- **Nothing may snapshot a colour.** `new SolidColorBrush(slot.Color)`, a
  `static readonly Color` or brush built from the palette, or a static array of palette
  colours freezes the view in one variant. Use the slot, `Wash`, `InkOn`, `Derived`, a
  property, or read `.Color` inside `Render`. Track colours:
  `ArrangementView.TrackBrush(index)`.
- **Accent = live or chosen, only.** Playing, selected, the playhead, the loop, a toggle
  that is on, a chosen segment, menu hover, the device power switch, and a value control
  *while hovered or dragged*. If it is orange and none of those, it is wrong. **Resting
  values are neutral `VizInk`** — knob arcs, fader and slider fills, value bars, graph
  curves, waveforms. A modulation arc keeps its source chroma. There is no second accent.
- **Semantic fills with derived ink.** Mute on = `Mute` (amber), solo on = `Solo` (blue),
  arm / record on = `Record` (red), solid, with `NotaPalette.InkOn(fill)` for the text or
  glyph — never a fixed label colour on a themed fill. Green is positive status and the
  meter's safe range. Graph chromas (viz ink · teal · rose · blue) live only inside graphs.
- **Seam between, rule within.** Panels meet on `Seam` and so do keys in a segmented
  group; items inside a panel are divided by `Rule` (separators, field edges, graph
  frames).
- **Flat docked, blur only floating.** No gradients, glow or textures. Depth is a tone
  step + a 1px seam + the `Shadow.Raised` top bevel on raised controls. Only a floating
  layer drawn in the main window (`Shadow.Popover`, `Shadow.Modal`) carries a blur; menus
  and popups get a seam ring only (Avalonia clips a popup's shadow at its window edge).
- **Radii 2 / 3 / 4.** `Radius.Clip`/`Badge` 2 for inner keys, rows, clips, menu items;
  `Control`/`Tile`/`Panel`/`Body`/`Pill` 3 for controls, cards, graph windows, popovers;
  `Modal` 4 for modals only; `Docked` 0; `Bar` 1 for bars inside a plot.
- **Geist for words, Geist Mono for every number a user reads.** Names are never mono.
  Nothing under 7 px.
- **Sentence case, no tracking.** Route labels through `NotaText.Label` (it sentence-cases
  caps literals and keeps acronyms and units: `LFO rate`, `Gain dB`). Never
  `ToUpperInvariant()` a label, never set `LetterSpacing`.
- **Opacity is not a state.** Disabled and muted take the next ink step; use
  `Inactive.Set` for a subtree. The only allowed `Opacity` is a drag ghost.
- **State changes colour only** — never size, border width or position. Hover and colour
  transitions 120 ms ease-out; meters, playhead and spectra are never animated.
- **Numbers are set, not printed.** The app installs a display culture (point decimal,
  U+2212 minus). Put a thin space (` ` in source) before units, keep precision fixed
  (dB one decimal, tempo two, percent whole, Hz up to 999 then `3.2 k`) — use `NotaNum`
  helpers.
- **Icons are geometry.** `Glyph` / `GlyphKind`: a round-capped 1.5 px stroke at 16 px
  (scaled), play and record filled. No unicode symbols (`■ ▶ ● ✓ ★ ▾`…) and no emoji as
  text. `·` separates meta; `→` in prose is fine.
- **Copy:** English. Labels one word where it fits, no vowel-dropped contractions
  (`Feedback`, not `Fdbk`; `Freq`/`Reso`/`Thresh` are allowed). Tooltips short and
  verb-first. Empty states are one Ink 5 line.

## Device cards

- **700 × 260** (`DeviceCardKit.CardH`; width exceptions are listed in `DESIGN.md`): panel
  body, radius 3, seam frame.
- **Header 22:** a raised strip with the `Shadow.Raised` bevel. Name left; preset picker
  `‹ Name ⌄ ›` (when the device has presets), the processing-type badge (mono, muted,
  sentence case) and the power switch (accent while on) right — nothing else. A/B, move
  and delete go in the header's right-click menu.
- **Body:** inset 6, sections on the panel tone with gap 5, titled in `DeviceSection`
  (muted 600), divided inside by rules; columns choice → work → output. Device text keeps
  the device scale (7.5–10.5 px) because the frame is kept.
- Values at rest neutral, the accent only for what is live or chosen; modulation shows its
  source chroma; graphs go through `NotaGraph` (well, rule frame, radius 3, `VizGrid`,
  `VizInk` primary curve, accent only on the active node, corner axis labels, no fills
  under curves).

## Adding a control

Reuse before writing: `Knob` (sizes snap to 34/36/44), `DeviceCardKit.KnobCell` (53 tall),
`SwitchTrack` / `DeviceCardKit.Switch` (18 × 10), `DeviceCardKit.Segments`, `SliderTrack` /
`DeviceCardKit.SliderRow`, `MiniFader`, `PanBar`, `VFader`, `DragNumber`, `MeterBar` /
`StereoMeter` / `GrMeter`, `Glyph`, `NaBadge`. Sizes and specs: `DESIGN.md` § Controls.

A new value control **must** match the interaction contract:

- Vertical drag, up increases, full range over ~140 px; Shift/Ctrl/⌘ for fine steps;
  `ns-resize`; a click never jumps the value; no horizontal drag
- Double-click restores the default
- Left button only — right-click must bubble to the CV-modulate / MIDI Learn menu
- `GestureBegin` / `GestureEnd` bracket `BeginAutomationWrite` / `EndAutomationWrite`
- Register with `MidiLearn.Bind`
- Live-follow refresher that **skips while dragging**
- Mono readout so width does not jump; the value is always visible, not only in a tooltip
- Its value drawn in `VizInk` at rest and the accent only while hovered or dragged

## Applying it (Avalonia)

- `NotaTheme.axaml` is merged in `App.axaml`; `NotaThemeService` applies the variant to both
  layers. `NotaNum.Install()` runs in `App.Initialize`.
- Buttons: default (raised, seam border, bevel), `primary` (weight and one tone step —
  not colour), `ghost`, `cell` (a readout well), `chip`, `tp-icon`, `tp-play`; a
  `ToggleButton` that is checked is a solid accent key with derived ink.
  `ToggleButton.seg` inside `Border.segmented` (keys butted on 1px seams).
  Containers: `Border.Panel`, `Border.Card`, `Border.well`, `Border.transport`,
  `Border.console`. Fields: `TextBox.field`, `TextBox.search`.
- Text: shell `Title`, `Heading`, `Name`, `Caption`, `SectionLabel`, `CellLabel`,
  `Readout`, `Value`, `Eyebrow`; device `DeviceName`, `DeviceSection`, `RowLabel`,
  `KnobLabel`, `KnobValue`, `Axis`.
- Elevation: `BindResource(Border.BoxShadowProperty, "Shadow.Raised" | "Shadow.Sunken" |
  "Shadow.Popover" | "Shadow.Modal")` — never a literal.

## When you change a token

1. Edit **both** branches in `NotaTheme.axaml` — `Dark` and `Light`.
2. Mirror the pair into the `NotaPalette` slot — the smoke test checks the pair.
3. Run `python3 scripts/design-html.py` and update the table in `DESIGN.md`.
4. Check both variants — in the app and in `DESIGN.html` (`?variant=light`).
